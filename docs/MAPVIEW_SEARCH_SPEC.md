## ปัญหาตอนนี้
ค้นหา (เช่น "korat") แล้วขึ้น "93 จุด" แต่แผนที่ซูมไปจุดเดียวที่ระดับ 14 และแผงขวามีการ์ดใบเดียว ผู้ใช้เลยไม่รู้ว่าอีก 92 จุดอยู่ที่ไหน
(markers ถูกกรองอยู่แล้วผ่าน `allLocations` ที่ใช้ `mapSearchQuery`)

## สิ่งที่ต้องทำ
### 1. แผนที่ตอนกำลังค้นหา
- แสดงหมุดเฉพาะจุดที่ค้นเจอ (มีอยู่แล้ว)
- **ค้นหาเสร็จ → `fitBounds` ให้เห็นทุกจุดที่ค้นเจอ** (ผู้ใช้เลือกแบบนี้ ไม่ใช่ซูมไปจุดแรก) ใส่ padding + `maxZoom` ประมาณ 15 กันกรณีเจอจุดเดียว
- ปุ่ม "ดูทั้งหมด N จุด" ที่มุมแผนที่ กดแล้ว fitBounds ใหม่
- หมุดที่เลือก = `activeIcon` (เขียว/ใหญ่) ส่วนหมุดอื่นใช้ icon ปกติ
- ตอนพิมพ์ให้ debounce ประมาณ 300ms ก่อน fitBounds เพื่อไม่ให้แผนที่กระตุก (หรือ fitBounds ตอนกด Enter + หลัง debounce)

### 2. รายการการ์ดตอนกำลังค้นหา
- หัวรายการ: "N ผลลัพธ์สำหรับ 'xxx'"
- **Desktop (lg+):** แผงขวาเป็นรายการการ์ด เลื่อนขึ้นลง (สูงเท่าแผนที่ 520px, `overflow-y-auto`)
  - การ์ดย่อ: ประเภท (badge), ชื่อ, ที่อยู่
  - การ์ดที่เลือก: ขอบไฮไลต์ + ขยายเป็นการ์ดเต็ม (snippet คอนเทนต์ + ปุ่ม เปิดใน Google Map / ดูคลิปต้นฉบับ / แก้ไขข้อมูล) ใช้ของเดิม
- **Mobile:** การ์ดอยู่ใต้แผนที่ ปัดซ้ายขวาได้ (`overflow-x-auto snap-x snap-mandatory` การ์ดกว้างประมาณ 85vw ให้เห็นขอบใบถัดไปนิดหน่อย)
- Performance: render ทีละ 30–50 ใบ แล้วโหลดเพิ่มด้วย IntersectionObserver (บางคำค้นอาจเจอหลายร้อยจุด)

### 3. เชื่อมการ์ดกับแผนที่
- กดการ์ด → `setSelectedPin` → แผนที่ flyTo ไปที่หมุดนั้น (`MapRecenter` ทำอยู่แล้ว)
- กดหมุด → `setSelectedPin` → รายการ `scrollIntoView({ behavior: 'smooth', block: 'nearest', inline: 'center' })` ไปที่การ์ดนั้น (ใช้ ref map ตาม key)
- Mobile: ปัดการ์ดจนใบไหนอยู่กลางจอ (IntersectionObserver threshold ประมาณ 0.6) ให้เลือกหมุดนั้นและแผนที่ตามไป **ต้องกัน loop:** ตอนกำลัง scroll เพราะเลือกหมุด ห้ามให้ observer ไปเลือกหมุดซ้ำ (ใช้ flag หรือ ref ตอน programmatic scroll)
- ใช้ key ที่คงที่ เช่น `${item.id}:${location.name}:${lat},${lng}` แทน index (ตอนนี้ Marker ใช้ `key={idx}`)

### 4. เลิกค้นหา
- ปุ่ม ✕ ในช่องค้นหา กดแล้ว `setMapSearchQuery('')` (ลบข้อความจนหมดเองก็ได้ผลเหมือนกัน)
- เมื่อเลิกค้นหา: หมุดทุกอันกลับมา, แผงขวากลับเป็นการ์ดเดียวแบบเดิม, หมุดที่เลือกล่าสุดยังเลือกอยู่ (ห้ามเด้งกลับไปหมุดแรก/Toronto) และไม่ fitBounds ทั้งโลก
- ป้าย "N จุด" ย้ายไปอยู่ข้างปุ่ม ✕
